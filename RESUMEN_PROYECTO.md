# Documentación del Proyecto: AFile

Todos los archivos generados durante las 6 fases de desarrollo de este proyecto se encuentran organizados en este directorio.

- **`src/`**: Contiene todo el código fuente del frontend (JS, CSS, Assets).
- **`netlify/`**: Contiene las funciones serverless del backend (Contacto y Estadísticas).
- **`pages/`**: Contiene las páginas secundarias (Contacto, Privacidad, Términos).
- **`tests/`**: Contiene las pruebas unitarias y E2E.
- **`index.html`**: Página principal del conversor.
- **`package.json`**: Dependencias del proyecto.
- **`vite.config.js`**: Configuración del empaquetador Vite.

## Fases Completadas
1. **Fase 1**: Configuración e Infraestructura.
2. **Fase 2**: Implementación de UI Base (WCAG).
3. **Fase 3**: Motor de Conversión de Imágenes (100% Client-Side con OffscreenCanvas).
4. **Fase 4**: Backend Serverless (Netlify Functions + Upstash Rate Limiting).
5. **Fase 5**: Consentimiento y Monetización (Cookies, AdSense, PostHog deferidos).
6. **Fase 6**: Auditoría, Accesibilidad y Pruebas E2E (Playwright).

El proyecto está listo para ser ejecutado con `npm run dev` o compilado para producción con `npm run build`.
